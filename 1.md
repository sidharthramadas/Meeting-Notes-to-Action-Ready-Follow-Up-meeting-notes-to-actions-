# meeting-notes-to-actions

An open-format AI skill (`SKILL.md`) that turns messy meeting notes or transcripts into a clean, action-ready team follow-up. Works in **Claude Code, ChatGPT, Codex, Cursor, and GitHub Copilot**.

## How to Use
1. Copy `SKILL.md` into your tool's skills folder (or install via `npx skills add <your-username>/<your-repo>`).
2. Invoke `/meeting-notes-to-actions` (Claude Code), `@meeting-notes-to-actions` (ChatGPT), or `$meeting-notes-to-actions` (Codex) and paste your raw notes.

## Example: Messy Input → Clean Output

### Input (Raw Notes)
> sync w/ maya & devin re: Q3 launch. landing page copy still feels too wordy—maya will rewrite hero section by thu. devin asked if legal signed off on the pricing badge, nobody knew. also we agreed to push webinar from oct 12 to oct 19 so product demo is ready. someone needs to update the invite. analytics tracking broke on staging, devin looking into it today.

### Output (Generated by Skill)
**TL;DR:** The Q3 launch webinar is moving to Oct 19 to align with the product demo, while landing page copy and staging analytics are being finalized this week.

**Decisions Made**
- Moved the launch webinar from **Oct 12 to Oct 19** so the product demo is ready.

**Action Items**
| Task | Owner | Deadline |
| :--- | :--- | :--- |
| Rewrite landing page hero section copy | Maya | Thursday |
| Debug broken analytics tracking on staging | Devin | Today |
| Update webinar calendar invite to Oct 19 | [TBD] | [TBD] |

**Open Questions / Blockers**
